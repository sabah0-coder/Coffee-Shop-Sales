# ☕ Coffee Shop Sales Dashboard

Interactive Excel dashboard for analyzing coffee shop sales, footfall, and product trends.

## 📊 Project Overview
This project presents an interactive Coffee Shop Sales Dashboard built using Microsoft Excel. It provides insights into sales performance, customer behavior, and product trends.

## 🎯 Objectives
- Analyze total sales and footfall across locations  
- Identify top-performing products  
- Understand customer purchasing patterns  
- Track sales distribution  

## 🛠 Tools Used
- Microsoft Excel  
- Pivot Tables  
- Power Query  

## 📈 Key Insights
- Total Sales: $698,812.33  
- Total Footfall: 149,116  
- Peak sales during morning hours  
- Coffee category contributes highest sales  

## 🚀 Conclusion
This dashboard helps in making data-driven decisions by analyzing sales trends and customer behavior.
